上空（800〜1200m）の仕掛けです。危ないものは灰色の金属（`hazard`・`metal`）、生き物はなし。

- 雲の足場（`Kabe.cloudPlat`）：下からすり抜けて上に乗れる白い雲。痛くないので縁取らない。消えない。
- ただよう機雷（`Kabe.mine`）：トゲの金属玉。その場で上下にゆれる。
- 曲がるトゲブロック（`Kabe.spikeBlock`・`Kabe.railPath`）：四面トゲの箱が、L字・コの字の道すじを往復する。縦長と横長。
- 突風の口（`Kabe.gustVent`）：壁の通気口。吹く前にふちが白く点滅し、吹いている間は風の筋（扇風機と同じ `Kabe.fanStreaks`）。
- 雷の柱（`Kabe.electrode`・`Kabe.lightningBolt`）：1マスの灰色の装置（乗れる・張り付ける）の間に白い光が走る。縦と横がある。予告で装置の先が光る。
- ぽよんブロック（`Kabe.jellyBlock`）：1マスの紫のぷるぷるしたブロック。乗る・張り付くと0.6秒でぷるぷるして、横へはじく。痛くない。
- 風車（`Kabe.windmill`）：短い羽3枚。回る棒の仲間。
