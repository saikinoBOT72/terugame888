ガチャ所です。本編では棚の上に立っていて、棚に降り立つとガチャの画面が開きます。

- ランタン塔：`Kabe.gachaHouse(g, P, x, y, t, 灯り)`。(x, y) は床の真ん中。細い土の塔（`terrain-light`、石の段）・鉄の扉と手すりと丸屋根（`metal`）・てっぺんのガラスの灯り（`glow`、中を結晶が回る）。灯台のように縦穴の上からでも見える。縁取りは `ink`（降り立つと何か起きるものなので）。
- 使ったあと（`灯り` が false）は、ガラスの灯りが消える。
- ガチャのフラスコ：`Kabe.gachaFlask(g, P, x, y, t, spin, 液の色)`。まるいガラスのフラスコに光の液、台の下で小さな火（光なので縁取らない）。`spin`（0〜1）で液が波打ち、泡が増え、栓のまわりから湯気。`液の色` は演出でレア度の色（`gem-*`）に変える（省略で `glow`）。ガラスが透けて、中を結晶が回るのが見える。
- 出た水晶のまわりの光：`Kabe.gemBurst(g, P, ★, x, y, t, k)`。レア度の色の、先の丸い光の帯がゆっくり回る（とがらせない）。`k` は 0→1 で広がる。
