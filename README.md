## 蹴り登りの塔（壁蹴りローグライク）

`index.html` をブラウザで開くだけで遊べます（ビルド不要・1ファイル）。

- **操作**：タップ / Space / ↑ で反対側の壁へ蹴り跳ぶ。Esc / P で一時停止。
- **目的**：下から迫る溶岩より速く登り、各層の「出口」を目指す。
- **ローグライク要素**
  - 層ごとにトゲ・回転ノコ・コウモリ・光線・落石の配置がランダム生成（シード表示あり）
  - 層を突破するたびに強化を3択で1つ取得（並・稀・極のレア度、最大Lvあり）
  - コインで「引き直し」「HP回復」
  - 倒れたら1層からやり直し。最高記録はブラウザに保存
- **強化一覧**：鉄の心臓／薬草／空中蹴り／磁石／粘着手袋／強脚／守りの札／踏みつけ／強欲／冷気の結晶／トゲ砕き／金運の輪／疾風／不死鳥の羽
