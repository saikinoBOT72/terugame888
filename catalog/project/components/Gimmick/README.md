地上（400m〜）の仕掛けです。どれも機械（無機物）で、崩れる足場のほかは動きが時間だけで決まります。痛い所は `hazard`、本体は `metal`、縁取りは `ink`（`Obstacle` と同じ決まり）。

| 名前 | 地図の文字 | 描く | 動き |
|---|---|---|---|
| 振り子 | `O`（軸） | `Kabe.pendulum(g, P, x, y, 長さ, Kabe.pendAngle(t, {amp, period, offset}))` | 軸から下がった鎖の先のトゲ鉄球が左右にゆれる。鉄球が痛い |
| 筒 | `K`（左の壁）`k`（右の壁） | `Kabe.cannon(g, P, x, y, 向き, 光る)`、弾は `Kabe.cannonBall(g, P, x, y)` | 一定の間隔で鉄球を反対の壁までまっすぐ撃つ。撃つ前に口が点滅 |
| 杭 | `ZZZ`（壁につながった横の並び） | `Kabe.stake(g, P, 壁の面x, y, 向き, 長さ, 出ぐあい, 光る)`、状態は `Kabe.stakeState(t)` | 引っこむ → 点滅 → ぐっと長く突き出る。出ている間ぜんぶ痛い |
| 跳ね橋 | `BBB`（壁につながった横の並び） | `Kabe.bridge(g, P, 蝶番x, y, 向き, 長さ, 角度, 光る)`、状態は `Kabe.bridgeState(t)` | 下りきっている間は乗れる → 点滅 → 跳ね上がる → 下りる。動いている板は体を押し出し、板の速さをうつす（乗ったまま上がると上へはじかれる。バネより強くしない） |
| バネ | `S`（1マスがバネの箱） | `Kabe.spring(g, P, x, y, 縮み)` | 上に乗ると真上へ高く跳ね上がる（2段ジャンプも戻る） |
| 崩れる足場 | `%`（横の並び） | `Kabe.crumbleCell(g, P, x, y, 崩れかけ, t, seed, 組み上がり)` | 1マスずつ。乗る・張り付くと、触れたマスから0.12秒ずつとなりへ伝わり、0.6秒ゆれて（ひびが伸び、小石がこぼれる）かけらになって崩れる。3秒で下から組み上がる |

- 色はゾーンのトークンだけ。
- 到達チェックでの扱い：杭はいつも出きっている、崩れる足場はいつも床、バネはそのまま動きに入る。振り子・筒・跳ね橋は「無い」扱い（タイミングで避けるもの）なので、壁に張り付いた位置に届かない所に置く。
