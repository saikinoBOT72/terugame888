壁の発射口から向かいの壁へ横に走る光線です。点いている間だけ、触れるとダメージを受けます。

- くり返し：消える（`off` 1.4秒）→ 予告（`warn` 0.7秒）→ 点く（`on` 1.2秒）。`Kabe.beamState(t, {on, off, warn, offset})` で状態を読む。
- 予告は細い点線と発射口の点滅。終わりに近いほど速く点滅する（点滅は「もうすぐ危ない」の予告だけに使う決まり）。
- 点いた光線は `hazard`（影 `hazard-shade`、芯 `hazard-light`）、縁取りは `ink`。縁はギザギザにとがらせる。まわりの薄い光は光源なので使ってよい。
- 発射口は壁に付いた小さな部品（`corner-part`、`terrain-shade`）。触れても何も起きないので縁取らない。
- 色はゾーンで変えない（危険なもの）。
