壁のすき間から、地形のブロックがゆっくり出たり入ったりします。縦穴の幅が変わり、張り付ける面も動きます。

- 見た目はふつうの地形（`Kabe.terrain` と同じ描き方、縁取りなし）。違いは先の面のボルト（1マスおき）と、どこまで出るかを示す丸い点の列（`terrain-shade` 55%）だけ。
- 動きは `Kabe.wallOut(t, 周期, ずらし)`（0〜1）。周期は4秒くらい、端で少し止まる。ゆっくり、やわらかく。
- 描く順：`Kabe.movingWall(...)` を先に描き、動かない壁を上に重ねる（壁の中から出てくるように見える）。
- 危険なものではないので、とがらせない・点滅させない。
