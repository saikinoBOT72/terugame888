# terugame888

壁蹴りで縦に登るゲーム（作り直し中）。どれもブラウザで開くだけで動く。

- `index.html` — 本編（基本のゲーム。ローグライク要素なし）。D：地形の線、V：パーツの到達チェック
- `simulator.html` — 壁ジャンプの動きだけを試せるシミュレーター
- `catalog/project/` — 統一カタログ（絵の決まりごと・ゾーン4つの色・素材の見本・キャラ4案）の元ファイル。`README.md` が決まりごと、`components/bundle.js` が全素材を描く描画ライブラリ
- `underground-assets.html` — 地下アセット帳：キャラ4案、地形・敵・飾りの改良版、新しい障害物アイデア12個
- `assets.html` — 見た目の方向性4つ（ドット絵／影絵／フラット／ネオン）と効果音2系統の見本帳
- `STAGES.md` — パーツの描き方、つなぎ方のルール、詰まないかのチェック
- `IDEAS.md` — 決まったことと、アイデアの候補一覧
