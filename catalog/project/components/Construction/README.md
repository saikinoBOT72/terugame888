すべての素材を同じ5つの手順で描くための見本です。

1. **形**：シルエットだけを1色で置く。丸いか、とがっているか（危険か）をここで決める。
2. **縁取り**：触れて何か起きるものだけ。プレイヤーは `player-line`、敵とトゲは `ink`、太さ `outline`。地形は縁取らない。
3. **影**：形を右下に `shade-offset` ずらした残りを影色にする。2段だけ。
4. **光**：左上に白い楕円を1つ（`highlight-opacity`）。地形は上の面の明るい縁（`terrain-light`）。
5. **描き込み**：顔・マフラー・苔・粒など。1マスに3つまで。

上の段がプレイヤー、下の段が地形のブロックです。
