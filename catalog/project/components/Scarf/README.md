プレイヤーのいちばんの目印、赤いマフラーです。

- 色は `scarf`（裏側 `scarf-shade`、しま `scarf-stripe`）。ゾーンで変えない。赤はプレイヤーの着せ替え（マフラー・帽子など）とHPのハートだけ。
- 首に巻く帯と結び目＋長いしっぽ（体の高さの約1.8倍）。先は燕尾（2つに分かれる）。
- 帯は体の丸みに巻きつける：前ほど下がり、両はしは体の線の外へ少しふくらんで後ろへ回りこむ（はしは暗く）。帯のしまは縦。はしほど間がつまって細くなる。形の数値は `Kabe.SCARF`（`chara.html` でいじれる）。
- しっぽは体より少し遅れてついてくる。止まっているときもゆっくり揺れる。
- 縁取りは `player-line`、太さ `outline-small`。
