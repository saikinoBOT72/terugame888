# terugame888

壁蹴りで縦に登るゲーム「壁蹴りタワー」。どれもブラウザで開くだけで動く。

- `index.html` — 本編（D：地形の線、V：パーツの到達チェック）
- `simulator.html` — 壁ジャンプの動きだけを試せるシミュレーター
- `catalog/project/` — 統一カタログ（絵の決まりごと・ゾーン4つの色・素材の見本・プレイヤー）の元ファイル
- `tools/` — 確認用スクリプト（到達チェック、自動プレイ、カタログの表示）
- `IDEAS.md` — 決まったことと、アイデアの候補 ／ `STAGES.md` — パーツの描き方とつなぎ方
- `CLAUDE.md` — 作業メモ（Claude 用）
