着せ替えと、そのガチャの素材です。

- 通貨は **ろうそく**（`Kabe.candle`）。プレイの終わりに 100m ごとに1本。白いろうに、たれ・芯・あたたかい火。
- ガチャの器は **石灯籠**（`Kabe.gachaLantern`）。ろうそくを入れると窓の火が光り、火の色がレア度を予告する（ミント★・青★★・金★★★、水晶と同じ色）。
- 分類は2つ（`Kabe.OUTFIT_ITEMS`）。いま着ているものは `Kabe.OUTFIT`（`wear`・`hat`・`hatColor`）と `Kabe.SCARF.color`（着るものの色）。まとめて出し入れは `Kabe.outfitGet()`・`Kabe.withOutfit(look, fn)`。
  - **着る**（首まわり・どれか1つ）：しましまマフラー・マント（すそまでの長さで背中にそってたれる。重い布なのでひもの動きは半分だけ（`CAPE.follow`）、体から大きくはみ出さない。裏地と金の留め具、すそは丸い山3つ）・おおきなリボン（首の後ろの蝶結び、はし2本）・すずのくびわ（金の鈴が振れる）。
  - **着る** の服：ポンチョ（肩からすっぽり、すそは丸い山4つ・しま2本）・サンタのふく（上着・白いふわふわのすそとえり・黒いベルトに金のバックル）・コート（丸いえり・前あわせ・金のボタン2つ）。服は体の線（`sheetPath`、形の数値は `SHEET_O`）を少し太らせて上とすそで切り出す。すその波は服の下から見える。
  - **かぶる**（なしでもよい）：ニットぼう（折り返しのうね・ぽんぽん）・まほうのぼうし（やわらかく曲がる先に丸い玉）・むぎわらぼうし（色のリボン、はしがなびく）・おうかん（金の冠、先は真珠、前に色の宝石）・サンタぼうし（白いふち、後ろへたれる先に白いぽんぽん）・リボン（頭の上の蝶結び）・てんしのわっか（頭の上にうかんで上下する輪）。
  - **小物**（なしでもよい）：あめ（食べる玉を口に、棒が外へ）・クリスマスキャンディ（曲がった方を口に引っかけて、まっすぐな方が前下へたれる）・バラ（くきを横に）は口にくわえる（口は両目のまん中の下・頬のあいだ `MOUTH`。口は物のうしろに描く。向きは `MOUTH_AIM`。目のまわりは描かないので、くわえた物は目にかからない）。ほしのステッキは前の手で持つ（星の先は丸める）。いま持っているものは `Kabe.OUTFIT.prop`・`propColor`。
- どれもプレイヤーの縁取り（`player-line`）・2段の影・光は左上・内側の細い線は1つの部品に2本まで。とがった形は使わない（三角の帽子の先も冠の山も丸い玉で終える）。
- 動きはマフラーのひもの点（`Q.scarf`）を使う：体に遅れてついてくる・跳ぶと後ろへ流れる・風に流れる・2段ジャンプを使い切るとしおれる。マント・リボンのはし・むぎわらのリボンはひもにそって流れ、ぽんぽん・帽子の先・鈴はひもの流れの向きに振れる。
- 色：しましまマフラーは `Kabe.SCARF_COLORS`、ほかは `Kabe.OUTFIT_COLORS`（どちらも あか をふくむ8色・レア度つき。赤はプレイヤーの着せ替えとハートだけ）。かぶるものの色は `Kabe.hatPal`。ハートの赤（`scarf`）は着せ替えで変えない。
- 品物のアイコンは `Kabe.outfitIcon`（x, y が絵のまん中）。体が無いので、首の輪は後ろ側も描き、しっぽは下へたらす。
