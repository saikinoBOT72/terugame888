ローグライクで拾うもの・装備するものです。

- **結晶**（お金）：`Kabe.mote(g, P, x, y, t, 大きさ, seed)`。ゾーンの `glow` の光の粒。形のない光なので縁取らない。ぼんやりした光＋十字のきらめき＋白い芯で、大きさ1以上ならまわりを小さな粒が回る。
- **水晶**（装備）：`Kabe.gem(g, P, 種類, ★の数, x, y, 大きさ, t)`。ガラスの六角柱（案A）。半透明で背景が透け、左の面は明るく・右の面は影・上の面は白く透ける。中に光があり、印は中に沈んで見える。触れて何か起きるものなので `ink` で縁取る。先は短くして、トゲ（危険）と区別する。
  - 色はレア度で決まり、どのゾーンでも同じ：★ `gem-mint`、★★ `gem-blue`、★★★ `gem-gold`。
  - 形でもレア度が分かる：★★ は横に小さな柱1つ、★★★ は柱2つ＋きらめき。
  - 真ん中に効き目の印（水晶の影の色をさらに暗くした線）：欲ばり＝3つの粒、ホバリング＝かさ、かべすべり＝壁と下向きの矢印、3段ジャンプ＝上向きの山3つ、予測線＝点の弧と輪、振り向き＝左右の矢印。
  - 種類と★の数は `Kabe.GEM_KINDS`、並び順は `Kabe.GEM_ORDER`。
- **装備の枠**（画面の表示）：`Kabe.gemBadge(g, P, 種類, ★, x, y, t, {lv, cool, r})`。丸い板に水晶、ふちはレア度の色、下にレベルの点3つ。`cool`（0〜1）はリチャージの残りで、暗い扇形が減っていく。種類が `null` なら点線の空き枠。
