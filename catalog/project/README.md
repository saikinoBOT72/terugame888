ゲームの絵は、すべてこのカタログの決まりで描きます。ゾーン（地下・地上・上空・宇宙）ごとに変えてよいのは **色とモチーフ** だけです。形・線・影・質感・解像度・動きは、どのゾーンでも同じにします。色はゾーンをテーマにしたトークンで、描画は `components/bundle.js` の `Kabe` を使います。

## いちばん大事な5つ

1. **安全なものは丸く、危険なものはとがらせる。** 地形・プレイヤー・飾りは丸み、トゲだけがとがる。
2. **触れて何か起きるものだけ縁取る。** プレイヤー・敵・トゲに縁取り（`outline`）。地形・背景・飾りは縁取らない。
3. **影は2段、光は左上。** ベース色と影色の2色だけ。グラデーションで影をつけない。
4. **1マス（`cell`）に描き込みは3つまで。** 地層の線1本・粒1つ・縁の飾り1つ。
5. **プレイヤーがいちばん明るい。** 明るさは 背景 ＜ 地形 ＜ 動くもの の順。

## 解像度とサイズ

- 画面は横360px（20マス）×縦640px。1マスは `cell`（18px）。地形はすべてマス目に合わせる。
- いつも **実寸で** 描いて確かめる。拡大した見本は確認用で、拡大して初めて見える描き込みは入れない。
- 最小の部品は 1.5px。線は `outline`（1.15px）、小さな部品は `outline-small`（1px）、内側の細い線は `line-inner`（0.7px）。
- プレイヤーは `player-width` × `player-height`（21×25px、少し縦長）。敵はプレイヤーより一回り小さく、トゲは半マス（`cell-half`）1本。
- 斜めの壁は **45度だけ**。

## 形

- 地形のブロックは、空間に面した角だけを `corner-block`（6px）で丸める。となりも壁の角は丸めない（つながって1つの塊に見える）。
- 台座や金具など小さな部品の角は `corner-part`。画面の表示の板とボタンは `corner-pill`。
- とがった形（三角・針・稲妻）は、危険なものだけに使う。飾りの結晶は先を短く、色を `glow` にして危険と区別する。
- 生き物は「丸い体＋小さな手足」。手足は体に付けず、少し離して浮かせてよい。

## 線（縁取り）

- プレイヤー：`player-line` で縁取る。太さ `outline`。手・足・マフラーは `outline-small`。
- 敵とトゲ：ゾーンの `ink` で縁取る。
- 地形・背景・飾り：縁取らない。上の面の明るい縁（`terrain-light`）と下の面の影（`terrain-shade`）で形を見せる。
- 縁取りは形の外側に付ける（形を塗ってから外側へ太らせる）。中の線は `line-inner` で、1つの部品に2本まで。

## 影と光

- 光は左上から。影は形を右下に `shade-offset` ずらした残りの三日月で作る。大きな部品は1.9px、小さな部品は0.5px。
- ハイライトは左上に白い楕円を1つ。不透明度は `highlight-opacity`（プレイヤーは0.9まで）。
- 地形は奥ほど暗くする：空間に面したマスは `terrain`、1マス奥は `terrain` と `terrain-deep` を半分ずつ、2マス以上奥は `terrain-deep`。
- 丸いぼかしの光を使ってよいのは、光る飾り（`glow`）とランタン・溶岩などの光源だけ。明滅は `glow-pulse` 以内。

## 質感

- 平らな面＋少しの粒。紙・布のテクスチャ、ノイズ、細かいグラデーションは使わない（背景の空のグラデーションだけは使ってよい）。
- 地形の面：地層の線（`terrain-line`）を1本。粒（`terrain-grain`）は半分くらいのマスに1つ。
- 上の面：縁の飾り（`accent`）。地下は苔、地上は草、上空は雲のふち、宇宙は星くず。上の面の4つに1つに光る飾り（`glow`）。
- 下の面：垂れるもの。地下と地上は根っこ、上空は霧、宇宙は小さな結晶。

## 色

- **ゾーンで変える色**：`bg-*`、`far`、`strata-*`、`terrain*`、`accent*`、`glow`、`ink`、`enemy*`、`rise*`、`ui-*`。ゾーンの色はまだ仮で、決まりを守れば変えてよい。
- **どのゾーンでも変えない色**：プレイヤー（`player-*`）、マフラー（`scarf*`）、危険なもの（`hazard*`）。
- 赤（`scarf`）はマフラーとHPのハートだけ。危険なものは、それより明るいコーラル（`hazard`）にして、形もとがらせて区別する。
- 上空は雲が白に近い。雲の上の面（`terrain-light`）は真っ白にせず、プレイヤーとは縁取りで見分ける。
- 敵の目は白目と黒目。プレイヤーの目は線。目の描き方で「自分」と「敵」を見分けられるようにする。
- 画面の文字 `ui-ink` は `ui-panel` と `bg-top` の上で、補足の文字 `ui-muted` は `ui-panel` の上で、どのゾーンでも 4.5:1 以上。

## 動き

- ゆっくり、やわらかく。ゆらぎは2〜3秒で1回り。羽ばたきだけ速くする。
- 跳ぶ瞬間は縦に伸び、着地はつぶれる（つぶれ・伸びは3割まで）。
- マフラー・すそ・しっぽは、体より少し遅れてついてくる。
- 光る飾りの明滅は `glow-pulse` 以内。点滅で目立たせるのは「もうすぐ危ない」という予告だけ。

## 文字と画面の表示

- 文字は `M PLUS Rounded 1c` 1つだけ（`menu-title`・`menu-heading`・`hud-number`・`body`・`hud-label`・`caption`）。
- 画面の表示は、85%の濃さの `ui-panel` の丸い板（`corner-pill`）に `ui-ink` の文字。画面の端から `hud-gap` 離す。
- HPはハート3つ（`scarf`）。減った分は `ui-ink` の25%。

## やってはいけないこと

- 地形や背景に縁取りをつける。
- 影をグラデーションでつける、3段以上にする。
- 45度以外の斜め。危険なもの以外をとがらせる。
- ゾーンに合わせてプレイヤーやマフラーの色を変える。
- 1マスに4つ以上描き込む。拡大しないと見えない描き込み。

## Kabe の使い方

- `Kabe.pal('underground')` でそのゾーンの色をまとめて取る（`tokens.css` の変数を読む）。
- `Kabe.terrain(g, P, Kabe.grid(地図), t)` で地形を描く。地図は1文字1マス（`#` 壁、`.` 空間、`^` トゲ、`/` `\` 45度の斜め）。
- `Kabe.ghost(g, P, 'sheet', 'cling', x, y, t, 向き, 倍率)` でプレイヤー、`Kabe.enemy(...)` で敵、`Kabe.rise(...)` で迫ってくるもの。
- 見本ページは `Kabe.zoneRow(要素, {w, h, draw})` で4ゾーンを並べて描く。

## キャラ

キャラは **B「すそ」**（白いおばけ・線の目・薄ピンクの頬・赤いマフラー、すそが丸い山で波打つ）に決定。いまは B をもとにした4案から選んでいるところです：B1「ふんわり」、B2「ながすそ」、B3「ずきん」、B4「ちびすそ」。1つに決めたら、ほかの3案はこのカタログから外します。

- すそは丸い山で作り、とがらせない（とがった形は危険なものだけ）。
- すそとマフラーは体より遅れてついてくる。跳ぶと後ろへ、張り付くと壁の方へ流れる。
