背景は重ねて作ります。どのゾーンも同じ組み立てで、モチーフだけ変えます。

1. 空のグラデーション（`bg-top` → `bg-bottom`）。グラデーションを使ってよいのはここだけ。
2. 波打つ帯2枚（`strata-a` / `strata-b`）。手前の地形の半分の速さで動く。
3. 遠景のシルエット（`far`）：地下は鍾乳石と石筍、地上は丘と木、上空は遠くの雲、宇宙は輪のある星。
4. 奥の縦穴の壁（`Kabe.bgMid`、スクロールの0.7）：左右のはしのシルエットと、段ごとの昔の物（はしご・看板・歯車・水道橋・風車など）。色は2つだけ（奥の色と、灯りや水の少し明るい色）。風車と水車の羽は本編で回す（`midSpins`）。
5. ただよう粒（`ui-ink` を5〜13%）。宇宙は星として少し濃く。

段ごとの天気は `Kabe.STAGES` の `weather`（wind・petals・sand・rain・motes）。本編は `Kabe.LIVE.grass = true` にして、苔と草の葉（`grassBlades`）を地形の絵に入れず、風で揺らして毎フレーム描く。

背景には縁取りも、描き込みの細かい形も入れない。
