キャラ案B1「ふんわり」（B すそ のなかの1案）です。今の「すそ」を整えた形です。すそが少し広がり、大きな丸い山が3つ。手は小さな丸で、体から少し離れる。いちばん素直でバランスがよい。

- 体：`player-body`、影 `player-shade`、縁取り `player-line`（`outline`）。すその内側にも `player-shade` の影。
- すそ：丸い山で波打つ（とがらせない）。跳ぶと後ろへ、張り付くと壁の方へ流れ、止まっているときもゆっくり揺れる。
- 顔：線の目（`line-eye`）と薄ピンクの頬（`player-cheek`）だけ。表情は目の線で変える（ふつう＝縦線、喜び＝∧、ダメージ＝＞＜、やる気＝少し傾いた線、まばたき＝横線）。
- 赤いマフラー（`scarf`）を首に巻き、長いしっぽが流れる。
- 上の段は拡大した5ポーズ、下の段は4ゾーンでの実寸です。

使い方：`Kabe.ghost(g, P, 'sheet', ポーズ, x, y, t, 向き, 倍率)`。
