敵はゾーンごとに変わりますが、作りは同じです。地下は顔のない4種類（トゲ鉄球・回転ノコ・掘削ドリル・火の玉）、地上は「ころ鳥」、上空は「もくもく」（雷雲の子）、宇宙は「かさクラゲ」。

- 地下の4種類：本体は鉄（地下の `enemy`）、触れると痛い所（トゲ・刃・ドリルの先）は `hazard`。火の玉は溶岩と同じ `rise` の色。顔は付けない。`Kabe.enemy(g, P, x, y, t, 倍率, 向き, 'ball' | 'saw' | 'drill' | 'fire')`。回転ノコのレールは `Kabe.rail(g, P, 左の壁の面, 右の壁の面, y)`。
- 地図の文字（本編）：`O` 鉄球（ゆれながら往復）、`S` 回転ノコ（レールの上を往復）、`D` ドリル（速く往復）、`F` 火の玉（大きくゆれる）。

- 丸い体（プレイヤーより一回り小さい）＋羽・耳・尾・触手。縁取りはゾーンの `ink`、影は2段、ハイライトは左上に1つ。
- 色は `enemy`（影 `enemy-shade`）。羽・おなか・耳の内側・触手は `enemy-light`。くちばし・足・稲妻は `glow`。
- 生き物の目は **白目と黒目**。目のふちを `ink` で囲み、ときどきまばたきする（プレイヤーの線の目と見分ける）。
- 羽は肩から回る（上げるとたたみ、下ろすと開く）。体は羽ばたきに合わせて上下し、足・尾・触手は少し遅れてついてくる。
- とがらせるのはトゲ・刃・稲妻など、危険を伝える所だけ。中の線（羽の骨・雲の継ぎ目など）は `line-inner` で1つの部品に2本まで。
- 羽ばたきだけは速くてよい。体のゆらぎ・クラゲの脈は2〜3秒で1回り。
