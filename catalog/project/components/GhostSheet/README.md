プレイヤーのキャラ「ふんわり」（B すその B1）です。これに決定しました。

- 形：頭は丸く、横はまっすぐ下りて、すそが少し広がる。すそは大きな丸い山が3つ（とがらせない）。手は小さな丸で、体から少し離れる。
- 体：`player-body`、影 `player-shade`、縁取り `player-line`（`outline`）。すその内側にも `player-shade` の影。
- すそ：跳ぶと後ろへ、張り付くと壁の方へ流れ、止まっているときもゆっくり揺れる。
- 顔：線の目（`line-eye`）と薄ピンクの頬（`player-cheek`）だけ。表情は目の線で変える（ふつう＝縦線、喜び＝∧、ダメージ＝＞＜、やる気＝少し傾いた線、まばたき＝横線）。
- 赤いマフラー（`scarf`）を首に巻き、長いしっぽが流れる。
- 大きさは `player-width` × `player-height`。上の段は拡大した5ポーズ、下の段は4ゾーンでの実寸です。

使い方：`Kabe.ghost(g, P, 'sheet', ポーズ, x, y, t, 向き, 倍率)`。ポーズは stand / cling / jump / air / hurt。
