ガチャ所です。本編では棚の上に立っていて、棚に降り立つとガチャの画面が開きます。

- 家：`Kabe.gachaHouse(g, P, x, y, t, 灯り)`。(x, y) は床の真ん中。土壁（`terrain-light`）・鉄の屋根と煙突と扉（`metal`）・光る丸窓（`glow`、中に結晶）・軒先のランタン・屋根の上の看板（結晶の印）。縁取りは `ink`（降り立つと何か起きるものなので）。
- 使ったあと（`灯り` が false）は、窓・ランタン・看板の光が消え、けむりも止まる。
- ガチャの画面の玉：`Kabe.gachaOrb(g, P, x, y, t, spin)`。鉄の台にガラスの玉、中を結晶が回る。`spin`（0〜1）で揺れて速く回る。
- 出た水晶のまわりの光：`Kabe.gemBurst(g, P, ★, x, y, t, k)`。レア度の色の、先の丸い光の帯がゆっくり回る（とがらせない）。`k` は 0→1 で広がる。
