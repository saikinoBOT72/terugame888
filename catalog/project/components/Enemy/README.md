敵はゾーンごとに生き物が変わりますが、作りは同じです。地下は「おおつばさ」（コウモリ）、地上は「ころ鳥」、上空は「もくもく」（雷雲の子）、宇宙は「かさクラゲ」。

- 丸い体（プレイヤーより一回り小さい）＋羽・耳・尾・触手。縁取りはゾーンの `ink`、影は2段、ハイライトは左上に1つ。
- 色は `enemy`（影 `enemy-shade`）。羽・おなか・耳の内側・触手は `enemy-light`。くちばし・足・稲妻は `glow`。
- 目は **白目と黒目**。目のふちを `ink` で囲み、ときどきまばたきする（プレイヤーの線の目と見分ける）。
- 羽は肩から回る（上げるとたたみ、下ろすと開く）。体は羽ばたきに合わせて上下し、耳・足・尾・触手は少し遅れてついてくる。
- とがらせるのは耳の先・稲妻など、危険を伝える所だけ。中の線（羽の骨・雲の継ぎ目など）は `line-inner` で1つの部品に2本まで。
- 羽ばたきだけは速くてよい。体のゆらぎ・クラゲの脈は2〜3秒で1回り。
