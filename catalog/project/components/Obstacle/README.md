トゲ以外の障害物です。どれも生き物ではなく機械（無機物）で、動きは時間だけで決まります（同じ時間なら本編も到達チェックも同じ位置）。

- 本体は鉄（`metal`、影 `metal-shade`、光 `metal-light`）。痛い所だけ `hazard` でとがらせる。縁取りはゾーンの `ink`。
- 鉄はトゲ（`hazard`）より暗くして、「本体」と「痛い所」を明るさでも分ける。
- 点滅は「もうすぐ動く」予告だけ（出入りトゲのすき間、シャッターのランプ）。

| 名前 | 描く | 動き |
|---|---|---|
| 出入りトゲ | `Kabe.popSpike(g, P, x, y, 向き, t, {in, warn, out, offset})` | 引っ込む1.4秒 → 予告0.6秒（先がのぞく）→ 出る1.2秒。痛いのは戻り値の `hurt` が true のとき |
| 往復ブロック | `Kabe.ironBox(g, P, x, y, w, h, 'x')`、通り道は `Kabe.track(...)` | 左右に往復。左右の面にトゲ。位置は `Kabe.slide(t, 周期, offset)`（0→1→0、端で少し止まる） |
| 上下ブロック | `Kabe.ironBox(g, P, x, y, w, h, 'y')` | 上下に往復。上下の面にトゲ |
| 回る棒 | `Kabe.spinner(g, P, x, y, 長さ, Kabe.spinAngle(t, 速さ, offset))` | 軸のまわりを刃の棒が回る。棒ぜんぶが痛い。軸は鉄 |
| シャッター | `Kabe.shutter(g, P, 左の壁の面, 右の壁の面, y, t, {open, warn, closed, offset})` | 開く1.8秒 → 予告0.8秒（ランプ点滅）→ 両側から閉じる1.6秒。戻り値の `close`（0〜1）が閉じ具合 |
| 扇風機 | `Kabe.fan(g, P, 壁の面x, y, 向き, 届く長さ, t)` | 風の向きへ押すだけで痛くない。風の幅は `Kabe.FAN_BAND` × 2 |

当たり判定（箱はトゲの面だけ痛いか、ぜんぶ痛いか。シャッターと箱に乗れるか）は、本編に入れるときに決める。
