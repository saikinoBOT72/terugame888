キャラ案A「しずく」です。頭は丸く、下へいくほど細くなって、先がくるんと巻く。手足は小さな丸。いちばんおばけらしい形で、跳ぶとしっぽとマフラーが2本流れる。

- 体：`player-body`、影 `player-shade`、縁取り `player-line`（`outline`）。
- 顔：線の目（`line-eye`）と薄ピンクの頬（`player-cheek`）だけ。表情は目の線で変える（ふつう＝縦線、喜び＝∧、ダメージ＝＞＜、やる気＝少し傾いた線、まばたき＝横線）。
- 赤いマフラー（`scarf`）を首に巻き、長いしっぽが流れる。
- 上の段は拡大した5ポーズ、下の段は4ゾーンでの実寸です。

使い方：`Kabe.ghost(g, P, 'drop', ポーズ, x, y, t, 向き, 倍率)`。
