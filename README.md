# おばけじゃんぴんぐ

壁を蹴って縦穴を登るゲーム。どれもブラウザで開くだけで動く。

## 遊ぶ
| | ページ | |
|---|---|---|
| ソロ | https://saikinobot72.github.io/terugame888/ | スマホ・パソコン。ホーム画面に置くとアプリになる |
| 2人対戦 | https://saikinobot72.github.io/terugame888/versus.html | 1つの画面を左右に分ける。コントローラー2台かキーボード |

## 開発用
- `pools.html` — プールとパーツの一覧（「ここから遊ぶ」でその高さから）
- `simulator.html` — 壁ジャンプの数値だけを試す
- `chara.html` — キャラの動き・表情・マフラー
- `catalog/project/` — 統一カタログ（絵の決まり・素材の描画ライブラリ `Kabe`）
- `tools/` — 確認用スクリプト（到達チェック・難しさ・自動プレイ）

## 書いてあること
- `IDEAS.md` — 決まったこと（ソロ / 2人対戦 / 開発用）
- `STAGES.md` — パーツの描き方・つなぎ方・プール
- `CLAUDE.md` — 作業メモ（Claude 用）
