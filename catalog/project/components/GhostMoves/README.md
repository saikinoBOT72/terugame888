おばけちゃん（B1「ふんわり」）の、動きを増やすポーズ21です。基本の5つ（`GhostSheet`）に足して、本編で状態に合わせて切り替えます。

| ポーズ | いつ | 顔・小物 |
|---|---|---|
| `kick` 蹴った瞬間 | 壁や床を蹴った直後の一瞬 | きりっ（`brave`）。体が前へ伸び、手とマフラーは後ろへ |
| `fall` 落ちる | 速く落ちているとき | まんまる目（`surprised`）。手をばんざい、マフラーとすそが上へめくれる |
| `land` 着地 | 床に着いた一瞬 | 目を細める（`squint`）。つぶれて手を横に |
| `wobble` グラグラ | 壁に長くついて落ちそうなとき | 困り顔（`worried`、まゆ付き）＋汗のしずく |
| `slide` 壁を滑る | かべすべりの水晶で滑っているとき | ほっとした目（`calm`）。マフラーが上へ流れる |
| `hover` ホバリング | 空中で踏ん張っているとき | にっこり（`happy`）。手を大きく広げる |
| `sleep` うとうと | 床で長く止まっているとき | 閉じた目（`sleep`）＋ z が3つ上へ |
| `cheer` やったー | ガチャのあと・節目の高さ | にっこり。両手を上へ |
| `kick2` 蹴った瞬間2 | 蹴ったとき（`kick` と半々で選ぶ） | きりっ。片手を前へ突き出す |
| `grab` 壁に着いた | 壁に着いた一瞬 | 目を細める。壁へつぶれ、マフラーが上へはねる |
| `clingUp` 壁で見上げる | 壁に0.9秒ついたら | 上を見る |
| `apex` てっぺん | 跳んで上がりきった一瞬 | ほっとした目。手を少し広げる |
| `flip` 宙返り | 2段ジャンプ（本編で1回転させる） | 目を細めて丸まる |
| `twirl` くるり | 2段ジャンプ・やったー（本編で向きを2回返す） | にっこり。手を横へ |
| `panic` わたわた | とても速く落ちているとき | 困り顔＋汗。手をばたばた |
| `landHeavy` どすん | 速く落ちてきて床に着いたとき | 目を細め、横につぶれて手を広げる |
| `dizzy` くらくら | ダメージのあと床に立ったとき | ぐるぐる目。頭の上を白い星が3つ回る |
| `stretch` のび | 床で待っているとき | ほっとした目。両手を上へ |
| `wave` 手をふる | 床で待っているとき | にっこり。片手をふる |
| `lookUp` 見上げる | 床で待っているとき | 上を見る |
| `fist` ガッツポーズ | 節目の高さを床で迎えた・ガチャのあと | きりっ。片手を突き上げる |

- ポーズの切り替えは急に変えず、手・マフラー・すそ・傾きを少しずつ寄せる（本編の `updatePose`）。
- ほかに本編で：まばたき（たまに2回）、向き替え（横につぶれて裏返る）、マフラーとすそが速さで流れる、待ちの動作は2秒から1.5秒ごとに選ぶ。
- 汗と z と星は `player-line` の線と `player-*` の色だけで描く（ほかの色を足さない）。
- 一覧は `Kabe.POSE_MORE`。描き方は基本と同じ `Kabe.ghost(g, P, 'sheet', 'fall', x, y, t, 向き, 倍率)`。
